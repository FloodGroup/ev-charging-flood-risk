## Input preparation

The flood sampler reads one GeoTIFF for each return period (10, 20, 50, 75, 100, 200 and 500 years). Build the mosaics from the [JRC depth tiles](https://jeodpp.jrc.ec.europa.eu/ftp/jrc-opendata/CEMS-GLOFAS/flood_hazard/) or supply matching local rasters. The local city-map builder uses terrain and OpenStreetMap background layers for orientation. Those layers do not enter the exposure or outage calculations.

For Figure 1 and Supplementary Figure 1, place two IEA tables in the `IEA_DIR` directory. Save the 2010–2025 historical EV charging-point rows for publicly available slow, fast and ultra-fast chargers as `iea_ev_charging_points_2010_2025.csv`. The country cross-audit sums `value` by `region` for `year` 2025. For the annual series, select the World rows and sum the three speed classes separately by year. Save the columns `year,slow,fast,ultra` in `iea_world_by_speed.csv`. The repository includes the prepared [world series](figures/Figure1/data/iea_world_by_speed.csv).

The Figure 5 covariate builder also accepts `EVFR_WB_GDP_CSV` and `EVFR_WB_POP_CSV` for WDI exports. Keep the WDI country metadata beside the GDP series using the World Bank naming convention (`Metadata_Country_` followed by the GDP CSV filename). The optional socioeconomic download script retrieves sources from the providers and may return more recent records. Use the referenced snapshots for comparison with the article.
